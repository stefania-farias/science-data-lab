# Science Data Lab

A personal learning project where I explore scientific and social questions using public data, Python and data visualization.

## First investigation

**How has the world's population changed over the last two centuries?**

This first investigation will explore historical population data and how it can be represented and interpreted through data analysis.

## Goals

- Learn the fundamentals of Python for data analysis
- Work with public datasets
- Create clear data visualizations
- Connect programming with scientific and academic questions
